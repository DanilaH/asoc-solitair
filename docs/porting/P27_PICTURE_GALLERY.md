# P27 · Апельсиновая оранжерея и альбом

В отдельном C8 preview (`VITE_CONTENT8_PICTURE=1`) игрок может открыть альбом с главного экрана или с результата. Открытие запускает пробное семидневное окно. Только первая победа уровня кампании во время окна добавляет 2 жетона и 3 монеты. Бонус виден отдельно от штатной победы, вехи и цикла. Повтор уровня и ежедневная раздача не дают эти жетоны. Участие добровольное.

У шести фрагментов свои цены 1, 1, 2, 2, 3, 3. Сумма трат вычисляется из сохранённых фрагментов, повторное касание не списывает жетоны. После окончания окна заработанные жетоны сохраняются. Собранная иллюстрация остаётся в галерее, 20 монет и подсказка выдаются одним сохранённым получением. Сохранённый альбом открывается при дальнейшем отключении активной выдачи. Изображение оранжереи создано отдельно для проекта.

35 unit-проверок в обычной конфигурации и шесть Playwright-тестов на 320 CSS px в двух профилях. Проверены обычное +10, последний выигрышный ход, открытие последнего фрагмента, выдача, reload и вход без начисления. Для Android необходимо подтвердить размер, крупный шрифт, фон, баннер и добровольность начала следующего уровня. [Сверка F1–F3](../qa/content-v8/F1_F3_RETENTION_META_SOURCE_TO_PRODUCT_2026-11-21.md). Шесть фрагментов, расписание и суммы — параметры нашего preview. Количество частей, доход и расписание в Hitapps остаются неизвестными.
