# Солитёр · генератор Hitapps и Rules4

Кандидат 0.20.8, Android code 49. База изменений — #213 поверх #212. Режим приёмки включается `VITE_HITAPPS_SOURCE_QA=1`. Android CI включает его в подписанном тестовом APK. Сертифицированные раздачи восстанавливаются по ID и при выключенной новой выдаче. Решения #210 действуют в обычном выпуске и сохраняются в кандидате.

## Как повторить

1. `npm run check` и штатные browser/Android jobs проверяют совместимый режим. `VITE_HITAPPS_SOURCE_QA=1` включает браузерную проверку выдачи и возобновления Rules4.
2. `npm run qa:hitapps-r4` проверяет каждую упакованную раздачу и вариант бюджета, сравнивает активные правила и второй переход на каждом ходе. В отчёте остаются seed, резерв ходов и число позиций с несколькими переносами. `HITAPPS_AUDIT_BOTS=1` добавляет исходные стратегии.
3. `HITAPPS_EVIDENCE_DIR=/path/to/research/games/association-solitaire npm run qa:hitapps-source-r4` проверяет Git-хеши исходных матриц и вызывает потребительские функции. Исходная ревизия исследования — `81da64b3f11acc1a4e4e9ff69c06e3baea5f8481`. Пройдены 5 972 строки специальных правил и 2 248 строк условий размещения, overrides и паттернов. Три префикса RNG являются модельными примерами.
4. Генерация идёт в `tools/content/build-hitapps-r4.ts`, отбор в `hitapps-source-pipeline.ts`, упаковка в `pack-hitapps-r4.ts`. Переменные `HITAPPS_BANK_VISITS`, `HITAPPS_BANK_SEEDS`, `HITAPPS_BANK_LEVELS`, `HITAPPS_BANK_MODE` задают ограниченный и повторяемый прогон. Метки `fixed-control` подтверждают отдельную контрольную раздачу, `feature-check` открывает проверку специальной механики, `campaign` допускает сертифицированную выдачу в QA.

## Числа и границы

Пороги 70/90 и штрафы −5/+10 переиспользуют утверждённую политику продукта. Коэффициенты Easy Deals 8/12/16 принадлежат версии `hitapps-balance-v1`. Проверка использует распределения запаса ходов и доли использованного бюджета, а также альтернативы на победном пути. Человеческая сложность и доля побед требуют отдельного плейтеста.

Два симулятора подтвердили победные маршруты 114 сертифицированных раздач кампании, включая локализованные варианты, и перепроверили 11 709 переходов. Цель Easy Deals достигнута в 83 из 114 раздач. В диапазоне 16–80 новые раздачи обслуживают 50 из 65 уровней. Остальные пользуются каталогом #212. Priority дал сертифицированные кандидаты для всех девяти проверенных уровней. Equality проверил по 100 кандидатов для тех же уровней и во всех девяти случаях вернул обычную выдачу после проверки допуска. Положительные условия и обмены Equality покрыты исходными матрицами.

Серверные параметры, весь исходный игровой цикл, порядок всех перекрёстных событий и списание хода остаются `SOURCE_UNKNOWN`. В Rules4 принята локальная цена в один ход за принятый игровой ввод, а автоматические эффекты происходят внутри того же хода. Локальные решения также определяют разрешённый поиск Магнита, эффект Молотка на обычную открытую карту, исходную раскладку отдельно заданных половинок, предотвращение конфликтов координат, выбор дополнительного скрытого золота и приз Gold Rush. Локальные условия и сравнение нативных функций перечислены в [ТЗ G0–G6](../../porting/HITAPPS_GENERATOR_AND_SPECIALS_TZ_2026-11-26.md).

Ветку выпуска и нативный пакет оценивать по точному коммиту в CI. Поведение на настоящем Android, рекламные SDK и коммерческая конфигурация остаются отдельными этапами приёмки.
