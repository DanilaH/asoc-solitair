# P15 · Джокер AZUR и отдельный сброс Undo

[Источник AZUR ARM64](https://github.com/DanilaH/mini-games-kit/blob/1cee602843a0fdbdf83cb104ab94c55dd15f752a/research/games/association-solitaire/2026-11-20-azur-shared-rng-joker/README.md) показывает выбор нижнего столбца через `Unity Random.Range(0,min(configuredBound,columns))`, создание открытой карты с типом 2, `PlaceCardForced`, условный `UndoSystem.Clear` и сигнал UI после ненулевого результата.

`modelAzurRandomJoker` воспроизводит эту условную последовательность на изолированных тестовых данных. Тестовый реестр cardIds отслеживает появление новой карты ровно один раз. Проверены положительная граница, отсутствие цели, нулевая, отрицательная и дробная границы, неверный RNG, повторный ID и отсутствие карты. Ошибка оставляет историю целой и не возвращает сигнал успеха. Оригинальные условия нулевой/отсутствующей цели и работа нового Joker после вставки остаются открытыми. 37 целевых unit-проверок прошли, включая действующий Joker и регрессии Rules3.

**NEEDS_OWNER для активации.** Реальная партия не подключена к модели. Для версии с оригинальным сбросом Undo требуется явное решение о потере истории, тексте предупреждения и переносе сохранений. Действующий ручной Джокер остаётся отдельной механикой. Цены, доступность и полученные оригинальные события — P36.
