# P10 · Карты во льду

[Hitapps native-static](https://github.com/DanilaH/mini-games-kit/blob/4b916c834e99b9208d194e2838dc2c082898ed2d/research/games/association-solitaire/2026-11-17-hitapps-shuffle-features/README.md) подтверждает шаблон layers/column/position, положительный FeatureLevelSeed, отдельный Shuffle и флаги 32/64. Действие оригинала при снятии слоя, цена, взаимодействие с Джокером и `placeOnJokerPositive` остаются UNKNOWN. Локальные пакеты из исследования не содержали активных Frozen-шаблонов.

**PRODUCT_ADAPTED.** В нашей пробной раздаче `campaign-c8-frozen-023-r1` карта с положительным льдом остаётся на месте, её нельзя перенести или накрыть, Джокер на её вершину не ставится. За каждую полностью собранную тему с каждой замёрзшей карты уходит слой. Остаток выводится из неизменяемого слоя в Deal v1 и уже собранных тем. Undo и перезапуск восстанавливают его из обычного сохранения. Колода сама лёд не меняет.

Отдельный флаг `VITE_CONTENT8_FROZEN=1` выдаёт пробную раздачу на свежем 23-м уровне. Обычный C8 использует старую раздачу. Обе версии доступны для восстановления своих старых попыток. У текущих раздач поле Frozen отсутствует и прежний порядок ходов сохраняется.

Два выигрышных маршрута без помощников повторены движком и независимой моделью. Пройдены 36 unit-проверок Frozen, Ordered, ключей, бонусных мест и правил; два сенсорных прогона на 320 CSS px проверили попытку нелегального переноса, снятие слоя, Undo, reload и победу. Физическое ощущение слоя/нажатия и живые исходные правила остаются P02/P36.
