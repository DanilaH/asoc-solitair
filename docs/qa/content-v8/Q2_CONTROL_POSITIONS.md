# Контрольные позиции C8 на Android

Установите **Ассоциации · Q2** и откройте **Контрольные позиции** на главном экране. Выбор начинает отдельную тестовую попытку. Повторный выбор той же позиции восстанавливает шаг из таблицы. После закрытия приложения кнопка кампании продолжает тестовую попытку с сохранённого места.

| Уровень | Перед ходом | Ходов осталось | Действие для контрольного прогона |
| ---: | ---: | ---: | --- |
| 15 | 97 | 22 | Повторить круг колоды |
| 21 | 87 | 84 | Перенести группу из второго столбца в первый |
| 45 | 1 | 191 | Перенести группу из второго столбца в четвёртый |
| 70 | 1 | 122 | Перенести карту из первого столбца во второй. Исход ветки пока неизвестен |
| 70 | 38 | 85 | Перенести группу из первого столбца во второй |

Для свободного выбора откройте позицию и покажите игроку только поле. Действия из таблицы нужны для отдельного контрольного прогона. [Протокол наблюдения Q2](Q2_HUMAN_ACCEPTANCE_AND_Q1_FOLLOWUP_2026-11-21.md)

## Проверяемая сборка

- Android-приложение Q2 занимает отдельный пакет `com.danilah.asocsolitair.debug.q2` с собственным хранилищем. Реклама и аналитика отключены в тестовой сборке. Для опыта с рекламой и чистого первого прохождения используется обычная 0.20.3.
- В браузере QA-профиль использует ключ `q2:asoc-solitaire.save.v1`. Включение требует одновременно `VITE_CONTENT8_PREVIEW=1` и `VITE_CONTENT8_Q2=1`. На Android дополнительно сверяется ID установленного приложения.
- Позиция строится из конкретной опубликованной раздачи, последовательность до указанного хода проходит через игровой движок. Он сохраняет доску, историю отмены и заработанные по пути монеты одной операцией SaveStore. Версия правил, раздача и число ходов сверяются при подготовке.
- Юнит-тесты сравнивают позиции с независимой моделью и проверяют декодирование сохранения. Браузерные проверки проходят весь выбор на 320 px, выполняют альтернативы касаниями и проверяют восстановление после загрузки. Физический плейтест с игроками открыт.

Ручная сборка использует `VITE_CONTENT8_PREVIEW=1 VITE_CONTENT8_Q2=1 npm run android:sync` и затем `ASOC_Q2_PROFILE=1 ./gradlew assembleDebug` из `native/android`. CI на ветках `feat/c8-q2-*` подписывает debug APK и сверяет его идентификатор. Проверка обычного release выполняется с обычным комплектом веб-ресурсов.
