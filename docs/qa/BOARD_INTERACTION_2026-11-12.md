# Доска: исправления по обратной связи — 0.9.3 / code 16

Исправления по десяти пунктам пользовательской обратной связи. Утверждённая компактная компоновка и простой казуальный стиль сохранены. Статус: [PR #17](https://github.com/DanilaH/asoc-solitair/pull/17) слит в main (`b8b9ebd823a0f353929b02a8107f87347f5987f5`), полный CI игрового кода пройден, APK и обе записи обновлены. Ниже отделены готовое поведение, автоматические проверки и телефонная приёмка.

## Что изменилось

| Замечание | Реализованное поведение |
|---|---|
| Карта прилетает из пространства | Draw начинает движение точно на верхней карте stock, рубашкой вверх; во время перелёта проходит через ребро и открывается в waste. Скрытая старая позиция узла больше не служит началом анимации. |
| Не видно предыдущих карт | Три карты образуют небольшой горизонтальный веер. У предыдущих слов видны повёрнутые боковые подписи, у изображений — маленькие предметные изображения. Играть можно только последнюю карту. |
| Колода плоская | Под верхней рубашкой есть слои. Толщина пропорционально уменьшается по мере расходования колоды, в том числе при большом остатке. Основание остаётся на месте, верхняя карта опускается вместе со стопкой. |
| Рука обучения нарисована движком | Используется сгенерированная прозрачная растровая перчатка. Обновлены и указатель на доске, и указатели помощников. Старый SVG удалён. |
| Перенос обрезается по границам поля | Один нативный pointer захватывается на доске; move/up отслеживаются в окне. Карта рисуется на поверхности размером с viewport над обычными элементами игры. Ограничение остаётся у настоящих границ экрана. |
| Возврат колоды резкий | Waste быстро и мягко переворачивается обратно в stock, с небольшим перекрытием анимаций. Последовательность слоёв согласована с первым следующим draw; порядок модели не менялся. |
| «Подробнее о награде» лишнее | Раскрывающийся блок удалён. Сумма награды, переход дальше и открытая косметика сохранены; начисления и дедупликация не менялись. |
| В теме смешаны картинки и слова | В пределах каждой категории все предметные карты показываются одинаково. Лидер категории остаётся словом. Выбор выполнен слоем отображения, без изменения опубликованных определений карт. |
| Просмотр отрывает от доски | Есть отдельная зона Aa. Можно поднести туда карту, прочитать локальное значение и отпустить: карта вернётся, ход, заряд и Undo не расходуются. Пояснение не становится модальным окном. Старый вход через нажатие сохранён для доступности. |
| Настройки меняют размер окна | Параметры заменяют внутреннюю часть паузы при фиксированных внешних границах. На коротком экране элементы доступны; панель не перескакивает к новому центру. |
| Палец закрывает карту и мешает попаданию | Карта поднимается на 68 CSS px за 80 ms, положение указателя отслеживается непосредственно. Цель определяется по видимой карте либо пальцу; допустимость проверяет прежний движок. Подъём, доведение и возврат не проходят через исходную позицию после сохранения. |
| После карты остаётся рамка | Постоянные прямоугольники исходных столбцов убраны. У пустых верхних слотов остаётся слабый знак; рамка наведения и короткий ответ цели привязаны к действию. |

Для нижнего положения колоды Aa находится в нижнем ряду, отдельно от верхних слотов. Прямое намерение перенести в Aa имеет приоритет, а случайное пересечение поднятой картой Aa не забирает допустимое попадание пальцем в игровой слот.

Закрытие попытки при последнем ходе теперь позволяет завершить короткий переворот/возврат до появления панели нехватки ходов. Это фиксированная задержка представления; сохранение и правила не зависят от завершения анимации.

## Основа и ограничения изменений

Повторно скачаны все три пользовательские записи: [Hitapps / S1](https://drive.google.com/file/d/1BLB3aShGKDB1qC0cukvoe-1zHTCX3IfX/view), [AZUR / S2](https://drive.google.com/file/d/1i3a71rYs9Ja9ETa0eyqGEpSjYh83zKEE/view), [Unico / S3](https://drive.google.com/file/d/1svpsKFIqZ7m4UcxQV4kJwV2nkFWw6-9s/view). Их SHA256 совпали с исходным [реестром](../research/WORD_SOLITAIRE_VIDEO_SOURCES_2026-11-09.json). Просмотрены контактные листы всей временной линии; у AZUR дополнительно разобраны 35–65 s и просмотр значения в 378–392 s. У Hitapps отдельно проверен веер в 280 s: боковые слова повёрнуты вдоль открытой полосы, изображения остаются миниатюрами. Это проверка записи, а не новое самостоятельное прохождение конкурентов на телефоне.

Обнаруженное на заполненной доске пересечение диагонального веера и плашек категорий исправлено горизонтальным веером по Hitapps; высота исходных рядов сохранена. Из AZUR взята связь «постоянное место Aa → перенос → локальное значение → возврат», из наблюдений за карточными играми — непрерывность stock/waste и заметное отделение руки от карты. Содержимое, оформление и ресурсы остаются собственными.

Добавлены 92 простых предметных изображения к уже принятому набору. Литературные формы, стройматериалы, напитки и погода остаются целиком словами: одинаковые книги, ёмкости и плохо различимые состояния не должны подменять смысл. Исходные 33 утверждённые картинки не перерисовывались. [Промпты, источники, хеши и прямоугольники экспорта](../art/BOARD_CATEGORY_ART_2026-11-12.json). Производственные ресурсы — `public/art/generated/subject-*.webp` и `public/art/ui/tutorial-hand.webp`; использована встроенная генерация, затем только кадрирование/экспорт.

Правила/content/balance остаются **2/5/3**. Ни `src/domain`, ни `src/content` не менялись: все 80 кампаний и 28 daily, состав, ID, начальные порядки, бюджеты и старые попытки сохранены. Единственный SaveStore, начисления, native receipts и точный kit SHA сохранены. Производственные настройки SDK, подпись релиза и публикация не затрагивались. Это приёмка управления и представления; сравнение интеллектуальной сложности или удовольствия в одном эксперименте с новой графикой не проводилось.
