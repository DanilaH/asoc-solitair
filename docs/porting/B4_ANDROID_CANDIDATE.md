# B4 · единый Android-кандидат

Задача #195. Основание: B0/C1 #196, B1 #197, B2 #198, B3 #199.

В новом L16 отдельный заряд случайного Джокера выдаётся за игровые монеты. Он не расходует ручной запас. Новый паспорт сохраняет стоимость 250 монет, равную цене обычного заряда, и использует отдельный ключ выдачи. Списание заряда при размещении, открытая карта и очистка Undo проходят одной записью после проверенного победного пути.

Ходы без лимита в этой версии стоят 120 игровых монет и действуют 60 секунд с момента атомарной активации. Это параметры нашего кандидата для проверки человеческого баланса. Уже заработанные и приобретённые права применяются по исходному контракту, прошедшие сохранения не получают новые тарифы. Ни одно из этих двух действий не вызывает платёжного провайдера.

| Проверка | Статус при подготовке |
| --- | --- |
| Изолированный C7 и общий C8 | Покрываются отдельными прогонами в CI. C8 имеет старые определения, новые паспорта, те же SaveStore и Undo. |
| Переход, поле, спецкарты, офлайн-экономика, бонус | Объединённый Chromium smoke на двух телефонах-viewport использует обычное меню приложения. |
| SDK test и SDK disabled | Android CI собирает подписанный тестовый APK и компилирует R8-вариант. Сверяет manifest и байты web. |
| Физический Android | `adb devices -l` в рабочей среде не показывает подключённого устройства. На устройстве остаются Back/insets/banner, касания, vibration/audio, реальное возвращение из фона и устойчивость с сетью. |
| Live и релизная подпись | Для подписанного производственного workflow нужны текущий ключ продукта, действительные три рекламные единицы и ключ AppMetrica. Разрешения новой паузы, жизней и reward-offers задаются явно через существующие release gates. Тестовая подпись идентифицирует QA APK. |
| Источники | Неизвестные параметры Equality, полной цепочки K2, Unico Magnet и live экономика перечислены в соответствующих ТЗ. Product-кандидат не служит доказательством исходного live-правила. |

Выпуск и размещение следует проводить после фактической общей Android-приёмки. Реальные покупки закрыты по решению владельца, их история и дорожная карта остаются в продукте.
