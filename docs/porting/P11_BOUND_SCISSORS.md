# P11 · Связанные карты и ножницы

Исследование [Hitapps Shuffle](https://github.com/DanilaH/mini-games-kit/blob/7298a8d805b19e2bd31c9a336cda9a17654a0359/research/games/association-solitaire/2026-11-17-hitapps-shuffle-features/README.md) подтверждает отдельный BoundPattern с координатами `boundCards` и `scissors`, гейты Shuffle, статусы 128/256. Взаимодействие ножниц при открытии, их фактическая цель, расход и Undo в оригинале пока UNKNOWN.

**PRODUCT_ADAPTED.** Заблокированную карту нельзя перенести, накрыть или использовать в качестве основания Джокера. Снятие связи происходит при переносе соответствующей карты «Ножницы» в верхний слот. Обычный ход стоит один ход по Rules 3. Следующий перенос другой карты не выдаёт повторный эффект. Добор ножниц только открывает карту. При Undo связь восстанавливается из текущих верхних слотов и собранных тем. Механизм льда остаётся независимым и проверен на той же доске.

Пятиколоночная раздача `campaign-c8-bound-024-r1` включается на свежем 24-м уровне только в `VITE_CONTENT8_BOUND=1`. Старые ID и неизменяемый ряд основного C8 сохраняются. Два маршрута проверены движком и независимым oracle; 38 unit-проверок и два сенсорных профиля на 320 CSS px прошли. В браузере подтверждены добор без снятия связи, перенос ножниц, Undo, reload и победа. Физический Android в P02, оригинальный способ снятия, цена и конфигурация — в P36.
