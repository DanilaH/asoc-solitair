Долговечный архив старого stock-only Shuffle использует прежнюю семантику Undo. Вариант hidden-pool с перестановкой без изменений возвращает отказ без расхода. RNG продукта не присваивается оригиналу.

Открыты состав и позиционирование оригинального Scissors/Puzzle после dispatch, параметры Hitapps Equality и оригинальные живые конфиги. Код K2 сопоставлен с mini-games-kit `b77af51259a85b8f6302c8ee3a5f7a5405bab954`. Готовность Android-сборки не заменяет физический запуск. Все 115 ID и 38 пакетов остаются в распоряжении проекта.
