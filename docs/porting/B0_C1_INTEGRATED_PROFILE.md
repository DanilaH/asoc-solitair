# B0/C1 · общий профиль кампании C8

Задача #195, ТЗ #194, реализация #196. Исходный код `c4215e18d54927a5ac73a350876f29852aa36861`, основание документации `52ecc4cf65b4bfe80de7bcb2e923c7322179850b`. Профиль `VITE_ASOC_PROFILE=c8-release-v1` одинаков для web и Android. SDK задаётся отдельно через `ASOC_AD_MODE`. Публичная выкладка остаётся за приёмкой B4.

| Выдача | Реальный состав | Проверка и продолжение |
| --- | --- | --- |
| L1–15 | Полные C8 уровни, аттестованные варианты R1, ручной Джокер, Ordered и Keys по существующим правилам | Старые идентификаторы и бюджеты сохраняются. |
| L16, новый старт | Обычный authored или адаптивный R2/seeded кандидат, конечный паспорт `c8-core-r1`, конечная колода, StockRestore, ручной и случайный Джокер | Все конечные паспорта проходят Rules3 и отдельный oracle. Случайный Джокер тратит один заряд существующего кошелька после доказанного размещения. Это правило нашей игры. |
| L17–80, новый старт | Полный каталог, адаптивные кандидаты там, где есть аттестация, запасной вариант R2 либо базовый. Верхний и нижний слоты на L22/L30/L40 | Покупка слота за игровые монеты сохраняет текущую политику. Комбинации спецкарт и слотов расширяются в B1. |
| Старые активные и отложенные партии | Архивные C1–C8, R1/R2, прежние recovery/Joker, seed47 и выданные Equality | Сохранённый ID, бюджет, доска и Undo используются напрямую. Отключение новой выдачи в сборке C8 сохраняет поиск интегрированных паспортов по ID. |
| Frozen, Bound, Puzzle, Golden, starter, Shuffle | Только действующие диагностические каталоги и ранее выданные попытки | Полноразмерные сочетания и конкретные правила допуска остаются в B1. |
| Equality | Аттестация и контролируемая выдача для QA | Источник реальной когорты и человеческий баланс остаются открытыми. |
| Жизни и Unlimited | Действующие жизни, восстановление по таймеру и монетами, применение уже сохранённого права Unlimited | Новое неплатное право и SDK-сценарии остаются в B1/B2. Диагностический бесплатный таймер в профиль не входит. |

Транзакция старта использует текущий координатор SaveStore. Сначала выбирается директором база, затем применяются допустимые правила Level 16, проверяются жизни, создаётся попытка. Неизменная схема 1, баланс 3. Победа по-прежнему привязана к номеру канонического уровня.

`npm run build` пишет manifest рядом с web. Он перечисляет версию политики, состояние возможностей, commit, версии приложения и сохранения, runtime pin, режим SDK, package ID и SHA256 каждого файла полезной нагрузки. Android CI сверяет manifest и побайтовые SHA с APK. Для подписанного release используется существующий signing workflow.

Открыто для B1–B4: приёмка на физическом Android, проверенный live SDK и общая частота рекламы, human balance, штатные каналы новых прав, полная матрица спецкарт, оригинальные live-конфиги, коэффициенты и стратегия Equality. Все 115 исходных ID и 38 пакетов остаются в реестре.
