# P25 · Все 15 семейств коммерческих предложений

`tools/content/commercial-offer-trial.ts` сверяет 15 независимых семейств [с E3](../qa/content-v8/E3_IAP_COMMERCE_SOURCE_TO_PRODUCT_2026-11-21.md) и использует офлайн-каталог P22. Ни одно предложение не доступно для оплаты.

| Семейство | Офлайн-контракт |
| --- | --- |
| Piggy Bank | Выигрыш считается один раз, копилка ограничивается, выдача сверяется с отдельным подтверждённым правом аккаунта и цикла. Отметка возврата сохраняется. |
| Play Pass | Бесплатная часть доступна в рамках сезона. Premium требует активного права ровно этого сезона. |
| Rotating / Birthday / Decoy | Ротация задана отдельным расписанием и SKU. День рождения требует добровольно предоставленного окна, даты рождения в модели нет. Сравнение показывает разные блага и не придумывает цены. |
| Starter / Welcome / Campaign | Starter имеет собственное 72-часовое пробное окно. Welcome требует подтверждённого отсутствия покупки. Campaign использует отдельное расписание. |
| Shop / coin packs / coin series / premium | Магазин охватывает 41 позицию, восемь пакетов монет и три премиум-набора. Серия монет берёт следующий пробный SKU после известной покупки. |
| VIP | Отдельное право аккаунта и срока с отзывом. |
| No Ads | Право выключает interstitial или interstitial с баннером; добровольные видео остаются доступны. |
| Unlimited | В каталоге три длительности. Истечение права проверяет журнал P23; временный правовой бюджет испытан в P19. |

12 unit-проверок покрывают ветвление, 41 позицию, возврат, точные права и разные области. Для реального продукта потребуются авторизованный P24, согласование индивидуальных условий, кошелёк и поведение после уже потраченного возврата, а для сезонных прогрессов P26–P32. Оригинальные цены, триггеры, длительности и состав выдач остаются открытыми. KIT IMPACT: REUSE типизированных прав и доказательств, модели продукта остаются в проекте.
