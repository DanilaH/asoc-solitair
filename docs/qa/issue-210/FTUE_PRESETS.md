# C8 · Первое знакомство с правилами

[Уточнение владельца и независимый аудит](https://github.com/DanilaH/asoc-solitair/issues/210#issuecomment-7184786704) проверяли PR211 `6e5143a`. Новые пресеты включены на `c8-release-v1` для первого прохождения. Старые C8/C7 определения, active/parked попытки и их Undo остаются адресуемыми. Повтор после зачтённой победы снова использует каталог. Размерность рядов и наличие зоны колоды в каждом новом пресете совпадают с исходной раздачей. Бюджет нового пресета оставляет столько же ходов после полного учебного пути, сколько исходный эталонный маршрут оставлял в старой раздаче. Награды используют действующие правила.

Направление действия привязано к ID и положению перед ходом. На экране указатель ждёт, пока обе стороны переноса доступны для касания. Точка определяется после входной, flip и collect анимаций. Законное действие вне учебного пути принимается. Дальнейшие подсказки могут возобновиться на совпавшем положении; с незнакомой позиции остаются обычные подсказки, ход, возврат и перезапуск. Введённые метки обучения переживают reload и Undo, как и остальные изученные правила. Состав урока и сохранённый прогресс не меняют состояние поля.

## Опциональные права и другие первые действия

| Когда | Что проверять в фактическом C8 и где находится доказательство |
| --- | --- |
| L16 · base/tight/relief/witness wrappers `-c8-core-r1-rights-r1` | Случайный Джокер, конечная колода, Restore, Unlimited. Контекст и цены в реальных меню помощников. Оплата и видео завершаются только существующим каналом подтверждения. Отсутствие средств не мешает обычному выигрышному пути. Права при переходах и восстановление поля проверяет `mvp-cohesion-core`. |
| L6 · верхний слот, L12 · нижний; исторические L22/L30/L40 | Разметка резервирует места. Подсказка предлагает только первый законный перенос **после** открытия слота; при отсутствии покупки остаётся обычный путь. Touch и Undo для обоих рядов и положения колоды покрывает `c8-ui-205`; `content8-bonus` покрывает варианты приобретённых и старых слотов. |
| L30 · первый Shuffle, включая три бюджета и сохранённые wrappers | В исходной позиции шести ID фиксирован seed 7 и доказанный путь из 113 действий. Подтверждение расходует существующий заряд; проверка в worker и повторная проверка SaveStore предшествуют списанию. Отмена, сдвинувшееся поле и недостаточный бюджет оставляют реальную экономику. После любого другого хода применяется обычный поиск. Доказательство — `c8-ftue-presets` плюс `mvp-cohesion-shuffle`. |
| L33/L36/L39 · следующие Shuffle | Свидетельства сохранены по точным ID базовых, бюджетных и поддерживаемых seed-раздач. `tests/fixtures/mvp-shuffle.ts` содержит достижимые позиции для проверки. В произвольной позиции действуют обычный поиск и отказ без списания. |
| Combo, Aa и Definition, низкий запас, продолжение | Игра показывает реальные накопления, бесплатное чтение и отдельные заряды. При отсутствии права текущие меню предлагают доступную альтернативу с её ценой. Прогресс/отказы фиксируют `mvp-cohesion-core`, `mvp-cohesion-retention`, `c8-ui-205`. |
| Дневная партия, бонусы, задания, оформление, события | Переходы, счета и права сохраняются в существующих каналах. `mvp-cohesion-retention`, `c8-casual-210` и `c8-surfaces-210` проверяют активные и архивные состояния. Для самостоятельного прохождения ни одно из этих окон не обязательно. |
| Архивные, бюджетные, альтернативные и локализованные раздачи | Новая учебная дорожка существует только для перечисленных точных ID. Старые раздачи продолжают использовать собственные правила и обычную контекстную помощь. Совместимость active/parked, базовые бюджеты и выдачу проверяют `integrated-release`, `c8-ftue-presets` и полный аудит геометрии. |

Браузерные записи L1 используют чистый профиль. Остальные начинают с предыдущей победы, воспроизведённой на опубликованной раздаче C8, и открывают следующий уровень обычной кнопкой. Предыдущие завершения представлены каноническими ID. Сам целевой Deal ID, поле, запас для платных опций и маркеры нового урока не подменяются. Для отдельной проверки L4 источник с нулём Undo явно помечен в сценарии. Снимки идут от начала до самостоятельных действий для 320×480 и 360×640.

## Источники и пределы

KIT IMPACT · REUSE. Из протокола FTUE применены отдельные проверки доступного действия, видимого результата и самостоятельного повтора. [AZUR preset routing](https://github.com/DanilaH/mini-games-kit/tree/main/research/games/association-solitaire/2026-11-20-azur-tutorial-preset) и [schema](https://github.com/DanilaH/mini-games-kit/tree/main/research/games/association-solitaire/2026-11-20-azur-preset-schema) подтверждают форму отдельного исходного пресета для L1. Более поздние сценарии в C8 спроектированы здесь. Реальная последовательность уроков оригинального AZUR, человек на физическом Android, TalkBack, реальные показатели понимания и рекламный SDK остаются отдельными проверками.


В кандидате 0.20.7 обучение и первые объяснения слотов участвуют в общем запрете принудительной рекламы. На первой встрече с закрытым слотом есть короткое сообщение. После наблюдения учебного действия guard хранится у попытки и пропускает две самостоятельные успешные команды перед следующей рекламной возможностью.
