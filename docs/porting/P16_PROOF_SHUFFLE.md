# P16 · Проверяемое перемешивание колоды

[Видео AZUR](https://github.com/DanilaH/mini-games-kit/blob/4b916c834e99b9208d194e2838dc2c082898ed2d/research/games/association-solitaire/2026-11-09-reference/WORD_SOLITAIRE_VIDEO_ANALYSIS_2026-11-09.md) показывает помощник с условием открытия. [Метаданные ShuffleAnimationController](https://github.com/DanilaH/mini-games-kit/blob/4b916c834e99b9208d194e2838dc2c082898ed2d/research/games/association-solitaire/2026-11-18-ui-feel-native/README.md) описывают поля контроллера. Какие карты переставляются, стоимость, активный тайминг и поведение Android оригинала остаются UNKNOWN.

**PRODUCT_ADAPTED.** Кнопка в пробном `campaign-c8-shuffle-029-r1` один раз бесплатно переставляет только остаток колоды. Текущие столбцы и сброс сохраняют свои карты. Seed определяет кандидат. Worker проверяет выигрышный путь в оставшемся бюджете с независимым oracle. SaveStore проверяет ту же попытку, версию состояния и доску, затем атомарно сохраняет новый порядок и признак использования. При остановке поиска, отсутствии доказанного пути или уходе приложения в фон исходное состояние остаётся целым.

Undo восстанавливает прежнюю колоду, право второго применения не появляется. Перезагрузка сохраняет состояние кнопки. Индикатор движения колоды запускается после успешно записанного решения и пропускается при reduced motion. Кошелёк и SDK-регистрация не участвуют.

24 целевые unit-проверки, два настоящих сенсорных сценария с Worker и ещё два браузерных прогона отмены через тестовый App bridge. На обычных Deal IDs управляемая кнопка скрыта. Эксперимент включён только через `VITE_CONTENT8_SPECIAL=shuffle`; физические касания и оригинальный порядок остаются P02/P36.
