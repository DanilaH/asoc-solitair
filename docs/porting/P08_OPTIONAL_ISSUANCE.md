# P08 · Опциональная выдача Equality

В `beginDeal` добавлен необязательный вход для заранее проверенной раздачи. Он выключен на игровых точках входа. Контрольный профиль передаёт явную конфигурацию с версией, известным тестовым сегментом и лимитом. При отключении, неизвестном сегменте, отсутствии подходящей раздачи, достижении лимита и после первой победы выдаётся обычная раздача.

Кандидат связывает исходный и новый Deal ID, версию, два разных проверенных следа позднего поражения и отдельный полный путь до победы. Solver в выдаче не запускается. Интеграционный тест получил следы P07, независимо проиграл победный маршрут и передал этот кандидат на уровне 16 через нормальную операцию сохранения.

- SaveStore атомарно сохраняет версию раздачи и политики, attempt ID и отдельные счётчики eligible/attempted/selected/issued/lost/completed. При ошибке записи исходная партия осталась нетронутой. При перезапуске и переключении на ежедневное задание сохраняются точные ID и режим. Restart сохраняет раздачу и привязывает счётчики к новому ID попытки; последующая победа может учитываться после ранее учтённого поражения.
- Факт поздних бот-поражений не создаёт игровых наград. Проверка +10, старые Rules 3, кошелёк, повторная выдача earned-реестра и штатная кампания сохраняют прежние механизмы.
- 26 целевых unit-проверок включают SaveStore, отключённый конфиг, неизвестный сегмент, ошибку хранения, восстановление припаркованной партии, Restart и завершение по известному выигрышному пути.

**NEEDS_OWNER для активации.** Для первой включаемой сборки требуется отдельное утверждение набора раздач и политики, регистрация выбранного неизменяемого каталога в резолвере, а также реальные наблюдения на устройстве. Контрольный каталог в тесте намеренно через отдельный резолвер. Исходные реальные сегменты и трансформация пар остаются P36.
