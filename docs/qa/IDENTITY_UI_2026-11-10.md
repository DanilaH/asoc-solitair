# 0.7.0: внедрение выбранного оформления

Поручение: перенести выбранный identity-макет в работающую игру. Два верхних слота выровнены с первыми двумя столбцами, названия категорий — одна строка; «Музыка» и «Кухня» вместо двухсловных названий.

## Изменение поведения и подачи

- Светлый главный экран с исходной эмблемой связанных карточек, одним основным действием и компактными входами в daily/цикл побед/оформление. Все 80 уровней доступны через отдельное окно выбора, с сохранёнными блокировками и предупреждением о замене попытки.
- Поле: компактный кошелёк/серия в одной верхней строке, самостоятельный ряд колоды и сброса, бюджет с отдельным Aa, левый ряд foundation, увеличенные четыре столбца и три светлых помощника. Верх/низ и обе стороны колоды используют ту же общую геометрию для отрисовки, hit-test, Hint, записей и Undo. При низкой доступной высоте поле масштабируется внутрь canvas; реклама не перекрывает его.
- У foundation видна последняя предметная карточка, короткий заголовок на вкладке и точки заполнения; лидер и остальные члены остаются в доменной модели. Ordered-порядок и ранги сохранены. Открытые передние слова центрированы; перекрытые карты показывают короткую верхнюю подпись.
- Пауза с крупным продолжением, общие кремовые диалоги и абрикосовые основные действия; прежние подтверждения рестарта/замены, настройки и помощники доступны.
- Nunito поставляется локально вместе с OFL-лицензией; игра не запрашивает Google Fonts. Эмблема переиспользована из принятого макета, рубашка и иконки — локальные векторы.

## Границы

Версии правил/контента/баланса остаются 2/5/3. Данные банка 80+28, IDs, порядок карт, бюджеты, награды, SaveStore/native ownership и пин kit не изменены. Короткие названия применены только при отображении; проверяется уникальность заголовков внутри каждой поставляемой раздачи. Нельзя выдавать браузерные записи за проверку звука/вибрации/FPS/native SDK на телефоне.

## Проверка

- `npm run check`: модель/платформа, все фиксированные победные пути, сохранность карт и геометрия четырёх положений колоды, TypeScript и production build.
- `npm run test:browser`: 80 уровней через реальные touch-команды, старый контрольный расклад, daily/campaign ownership, помощники, сохранения, ordered/Joker/keys, маленький экран и резерв баннера. Сценарии выбора уровней обновлены под явное открытие окна.
- `npm run qa:feel`: новый первый запуск и полноценная победа/Next, достижимое плотное состояние уровня 17, сбор категории/следующий ход/Undo/пауза. Запись 360×780; дополнительные снимки главного/плотного поля/нижней левой колоды — 320×568. Нет runtime debug bridge или вымышленных результатов.

Фактические результаты CI, APK и подпись фиксируются в VERIFICATION.md после завершения сборки.
