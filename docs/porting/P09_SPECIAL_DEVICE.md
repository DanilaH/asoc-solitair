# P09 · Приёмка Ordered, ключей и двух бонусных мест

**NEEDS_DEVICE.** ADB не видит физического Android. Повторены 34 unit-теста и 12 сенсорных проверок Chromium на 320 CSS px в двух профилях. Сохранены четыре механики и весь реестр из 114 ID. Для проверки SDK использовать [подписанный P01 APK](https://github.com/DanilaH/asoc-solitair/actions/runs/44928339856/artifacts/14716238019). Сценарии P09 доступны в обычной сборке, изолированный Q2-пикер нужен только для его контрольных позиций.

| Раздачи | Проверка | На устройстве |
| --- | --- | --- |
| `campaign-c8-special-017`, `campaign-c8-special-045` | Перенос Ordered начинается с №1, неверный пропуск сохраняет бюджет и инвентарь, независимые маршруты выиграны | Ошибочный перенос, текст причины, легальный перенос и читаемость на пяти столбцах |
| `campaign-c8-special-018`, `campaign-c8-special-026`, `campaign-c8-special-066` | Закрытая колонка не принимает перенос и не отдаёт карты, третий отдельный ключ раскрывает верхнюю карту в той же транзакции, Undo возвращает два ключа | Правый закрытый столбец, крупный шрифт, визуальный и тактильный отклик; повторить после reload |
| `campaign-c8-bonus-022`, `campaign-c8-bonus-040` | Верхний слот стоит 100 монет, в нём собирается ещё одна тема, право сохраняется с партией и через Undo | Стартовое, открытое и отменённое состояния, монеты, реальный earned/no-fill |
| `campaign-c8-bonus-030`, `campaign-c8-bonus-040` | Нижний столбец стоит 60 монет, подходит для временной группы, существует отдельно от верхнего. Отказ сохраняет обычную проходимость | Два места на одной доске, колода сверху и снизу, касания рядом с краями при активном баннере, монеты и earned/no-fill |

Для видео фиксировать provider phase и существующий ID попытки до/после. Earned после закрытия должно открыть своё место один раз, включая сохранённую кампанию при активном daily. Если после запроса партия успела измениться, осмотреть выдачу по точной связи `attemptId`/Deal ID и убедиться, что соседнее место остаётся закрытым. Сохранить данные до/после и запись реального касания по [P02](specs/05_SOURCE_DEVICE_ACCEPTANCE.md). Цены и расписание этих механизмов в оригиналах остаются отдельным исследованием.
