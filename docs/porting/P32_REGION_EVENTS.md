# P32 · Регионы и четыре отдельные механики событий

В [сверке F1–F3](../qa/content-v8/F1_F3_RETENTION_META_SOURCE_TO_PRODUCT_2026-11-21.md) регионы имеют каталог и порог уровня/звёзд. Для Cascade, Digging, LuckyWheel и EndlessTreasure полноценная исполняемая логика оригинала остаётся открытой. `tools/content/region-event-trials.ts` испытывает пять контрактов отдельно.

- Regions начисляет звёзды по единственной первой победе, требует уровень и строения-предшественники, списывает звёзды при открытии конкретного строения.
- Cascade выбирает допустимые окна по зависимости и приоритету для каждого места. Старые ожидающие призы при переключении сохраняются.
- Digging открывает выбранную ячейку за её цену, хранит находки, требует собрать набор перед получением. Повторное открытие не списывает жетон.
- LuckyWheel хранит точные целые веса и работает с явным входом равномерного генератора. Один жетон даёт одну сохранённую попытку, выдача отдельной операцией.
- EndlessTreasure проходит заданные шаги и главы с ценой и призом каждого шага, блокирует повтор ключа и сохраняет переход главы.

14 целевых unit-проверок и очередь из 114 механизмов. **BLOCKED_EXTERNAL** для порядка оригинального Cascade, конкретных действий и исходных вероятностей. Пробные правила разработаны отдельно и не активированы. KIT IMPACT: REUSE правил идентичности, событий и сверки источников.
