## E3. Lava Quest
Реализовать run state machine с event config, stage count, phase timers, cooldown, seed, initial bot count, sampled finalists и per-stage ranges. Для intermediate dropout — floorf32 bounds, memoized feasibility search, равномерный выбор среди допустимых кандидатов с инъекцией RNG, final drop=remaining−target. Отдельный равномерный fallback quotient/remainder при infeasible в собственной политике; не объявлять точным полный original RNG. Зафиксировать весь план при start; видимый animation/icon seed отдельно от результатов. После окончательного проигрыша очищать run и rebuild только на следующий допустимый run; Continue не равен финальному loss до утверждённого outcome. Сохранять достигнутые earned claims. Источник показывает семь first-try wins, число настраивается; не копировать как универсальное. Prize item=floorf32(total/max(1,finalistBots+1)), выдавать только при подтверждённой победе/claim. Все AI rivals обозначены как симуляция. Тесты zero/one bots, reversed ranges, impossible target/fallback, no negative survivors, reset seed, first try/restart/continue, cooldown, expired pending, double claim, visual plan not RNG input.
