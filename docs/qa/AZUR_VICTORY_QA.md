# AZUR. Проверочный режим выплаты за победу

[Issue #180](https://github.com/DanilaH/asoc-solitair/issues/180) · [Исследование kit #132](https://github.com/DanilaH/mini-games-kit/pull/132). В аутентифицированном AZUR 1.3.3.8/code244 подтверждены скомпилированная таблица выплат и вызов `AddCoins` из победного перехода. Живые значения сервера, точные исходные условия допуска бонуса и выдача x3/x5 остаются открытыми.

| Параметр | Скомпилированное значение |
| --- | ---: |
| Код 1, Easy | 25 |
| Код 2, Medium | 50 |
| Код 3, Hard | 100 |
| Код 4, Extreme | 200 |
| Остальные коды | 100 |
| Бонус при разрешении | 5 за оставшийся ход |

`VITE_AZUR_VICTORY_QA=1` выбирает неизменяемую версию конфигурации `azur-1.3.3.8-244-compiled-v1`. Эта версия использует свой ключ сохранения и не импортирует обычное сохранение. Версию конфигурации и ключ нужно менять вместе при замене таблицы. Сложность берётся из метаданных раздачи. Предупреждения «Очень сложный» и «Сложный» дают 4 и 3, обучающая раздача — 1, обычная кампания — 2. Неизвестный код использует fallback. Это продуктовый маппинг для проверки формулы.

Значения проверяются в пределах знакового 32-битного числа. В QA конечный остаток участвует в формуле, отсутствие числового лимита даёт ноль. У задачи дня остаётся собственная выдача. Текущая обычная формула 25 + 2 за ход применяется в стандартном профиле. Рекламные множители продолжают относиться к существующим коммерческим сценариям и выключены в этом QA-профиле.

Отчётливо разделены записанное начисление по `win:<attemptId>`, расчёт на экране и декоративный прилёт. Отдельное локальное событие QA фиксирует исходную сборку, код сложности, базу и бонус после записи. В результате показаны база, остаток ходов и прочие начисленные награды при наличии. Отмена анимации, повторный показ и копирование сохранённой победы во второе хранилище проверены как идемпотентные. Синхронизация независимых устройств, физический Android и данные живого сервера требуют отдельной приёмки.

KIT IMPACT · REUSE. Использованы SaveStore, аудио/переходы из #179 и существующая схема телеметрии. Числа AZUR и выбранный маппинг — часть проверки продукта.
