# Content 8 CORE-2 · проверенные части директора

База — [CORE-1 #49](https://github.com/DanilaH/asoc-solitair/pull/49). Preview 0.19.4 сохраняет локальную историю десяти первых прохождений. Записывается Clean, ExtraSteps после использованного продолжения или Restart с числом повторов. Поражение и повторы идут в историю текущей попытки. Reload, Undo и поздняя квитанция не ставят новый результат и не списывают ход. Повтор запускает ту же версию раздачи. Старые сохранения без полей истории начинают собирать реальные результаты по мере игры.

| Механизм | Какие ветки проверены |
| --- | --- |
| DynamicDifficulty | Окно 10, веса повторов, строгие границы процента, сброс penalty того же знака, signed-округление бюджета для stable moves. Конфиг и правила округления оценок live-оригинала остаются открыты. |
| EasyDeals | Офлайн-проверка наличия явной настройки по сложности, уровня, random/stable и порога предыдущих поражений. Цель задаётся нашим конфигом. Нативные `decCoef`, два lookup и ветвление после Paywall требуют дополнительной сверки. |
| Equality | Пробные политики реально выполняют Rules 3 на независимых копиях одной раздачи. Определённый LOST при 79% отклонён, при 80% принят, UNKNOWN отклонён. Успех другой политики отменяет выбор. Положительный seed, уровень, счётчик и whitelist проверяются отдельно. |
| FeatureLevelSeed | На Fresh первый подходящий Shuffle-аплаер переставляет колоду один раз. Невалидный pattern после перестановки даёт Failed. При уже подготовленном кандидате симуляции повторная перестановка пропущена. |

Офлайн-результаты кандидатов пока не влияют на выдачу в приложении. Для подключения нужны замороженные варианты с собственными ID, проверенный подбор на старте новой попытки и явная конфигурация. Пулы действующих уровней, исходные покупательские сегменты и частоты оригинала неизвестны. Условия выдачи +10 из фактического проигравшего состояния остаются в CORE-5.

Точное размещение трёх пар и расход общего RNG при таком размещении ещё требуют независимой сверки. До этого симулятор Equality работает на поданном, уже подготовленном кандидате. Код эффектов Lockers/Frozen/Bound подключается в CORE-4. Все связанные строки реестра остаются в работе.
