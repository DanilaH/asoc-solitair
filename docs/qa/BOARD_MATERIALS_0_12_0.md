## Изменения

Карта сохраняет верхний слой до посадки; hit order следует фактическому слою. Принимающее изображение остаётся до покрытия. У упорядоченной темы устранено наложение счётчика на правило. Звук, haptics и декоративная выплата следуют контакту; сохранение и выдача награды остаются немедленными. Flip звучит у ребра.

Последний ключ проходит открытие источника → перелёт → 3/3 и открытый замок → раскрытие освобождённой карты. Новый жест, Undo, пауза и новый sync отменяют только presentation. Обычная посадка получает один короткий блик и оседание; завершение темы — бумажный край и пять ограниченных частиц. Разворачивание Джокера остаётся HOLD.

Сгенерированы две рубашки, верхний и нижний слоты и открытый замок. Локально подключены под прежние cosmetic IDs; preview использует те же рубашки. [Brief, provenance и точные SHA](../art/BOARD_MATERIALS_0_12_0.json). Экспорт только crop/resize/WebP с исходной alpha, без перерисовки. Текст, счётчики и hitboxes остаются кодом. Геометрия, 33 предмета, политика слов/изображений, правила, банк, сохранения, экономика, SDK и kit pin сохранены.

## Что блокирует доставку

GitHub connector создаёт только UTF-8 blobs, CLI push/gh без авторизации. Пять готовых WebP требуют обычной загрузки в `public/art/generated` feature-ветки. Защищённый browserAuth не завершился; свежая вкладка GitHub показывает отсутствие входа. Следующий шаг — ручной вход, затем обычный file chooser с готовыми копиями `/workspace/shared/asoc-board012-upload/`. Не передавать изображения через base64/hex, не добавлять токены или обходные workflows. После загрузки проверить хеши, полный CI, подпись/code20/191 web-файл APK; только затем слияние и новая поставка. Main и предыдущий APK остаются0.11.0.
