# P24 · Проверка площадок для оплаты

Дата проверки 21.11.2026. Статус `BLOCKED_EXTERNAL`. Для проекта нет подтверждённого продавца с договором на игровые цифровые товары, включённым платёжным аккаунтом и доступом к sandbox. Каталог P22 остаётся отключённым, журнал P23 проверяется независимо.

Для выбранного продавца отдельно проверить реальные идентификаторы приложения и товаров, владение аккаунтом, разрешённое зачисление, способ чека и возврат. Сначала подтвердить sandbox покупку, отмену, восстановление и возврат с повторными webhook. Живой платёж и выплата требуют авторизованного аккаунта; тестовая транзакция их не подтверждает. Параметры доступа и ключи должны храниться на стороне продавца. Учёт P23 сохраняет только проверяемые идентификаторы операции.

Для RuStore серверная выдача различает `invoiceId` и `purchaseId`. `PAID` у расходуемого товара означает удержание средств до подтверждения, `CONFIRMED` означает окончательное списание, `REFUNDING` и `REFUNDED` различны. Будущий адаптер должен фиксировать авторизованное право перед подтверждением и обрабатывать возврат/отмену удержания по реальному контракту. Подключённый аккаунт необходим, чтобы сверить эту пару статусов на подписанном приложении. [Статусы RuStore](https://www.rustore.ru/help/work-with-rustore-api/api-subscription-payment/v2-purchase-invoiceid) · [Sandbox RuStore](https://www.rustore.ru/help/developers/monetization/sandbox/testing-sdk-pay).

KIT IMPACT: REUSE журнала заказов и доказательств. Нет нового SDK и изменений игрового интерфейса. P25 продолжает работу с офлайн-офферами.
