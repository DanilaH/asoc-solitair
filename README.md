# Солитёр ассоциаций

Портретная Android-игра для RuStore: собрать слова и изображения по категориям за ограниченное число ходов. Русские интерфейс и контент, локальная партия, без аккаунта и сервера.

**Состояние:** первая законченная браузерная партия, чистая модель, сохранение, подсказка, Undo и карточные реакции. Созданы Android-проект и сборочные процессы. Подключена нативная обвязка: реклама, аналитика, вибрация, audio focus и надёжное сохранение. Полный банк, модификаторы, мета и проверка SDK на телефоне остаются по [ROADMAP](ROADMAP.md).

## Запуск

Node 24.22.1, npm 11.9.0:

```bash
npm ci
npm run dev
```

Перетаскивайте всю доступную группу или выбирайте её тапом, затем нажимайте на цель. Карта категории запускает сбор в верхнем слоте. Колода открывает одну карту за ход. Повтор колоды сохраняет порядок. Подсказка показывает ход, игрок выполняет его сам. `Aa` включает просмотр открытой карточки.

```bash
npm run check
npx playwright install chromium
npm run test:browser
npm run qa:record
npm run android:sync
```

Android: JDK 21, Android SDK 36 / build-tools 36.0.0. Затем `native/android/gradlew -p native/android assembleDebug`. CI сохраняет debug с demo-рекламой и явно помеченный unsigned SDK-disabled R8 APK для проверки компиляции; отдельный ручной workflow собирает подписанные APK/AAB при наличии трёх `YANDEX_*_AD_UNIT_ID`, `APPMETRICA_API_KEY` и `ASOC_STORE_BASE64`, `ASOC_STORE_PASSWORD`, `ASOC_KEY_ALIAS`, `ASOC_KEY_PASSWORD` в GitHub Actions secrets. Режим live обязателен, test/live не смешиваются. Подпись и ключи не находятся в репозитории. Артефакт сборки сам по себе не подтверждает работу на телефоне.

## Структура и источники

- `src/domain` — правила, команды, инварианты, поиск продолжения; не зависит от Phaser.
- `src/content` — собственные карты, точная раздача и путь победы.
- `src/game` — Phaser, ввод, расположение и эффекты; Worker для поиска подсказки.
- `src/platform` — последовательный writer профиля/партии, нативные адаптеры, журнал выдач, аналитика, lifecycle и ограниченное аудио.
- [Документы проекта](docs/README.md), [решения](DECISIONS.md), [проверки](VERIFICATION.md), [переиспользование kit](docs/KIT_REUSE.md).

Референс-видео: [папка пользователя](https://drive.google.com/drive/folders/1W5uEIfwwR6vPzYsp5EYt1r2RFxuWCKgL). В Git видео, рекламные сцены и чужие игровые ассеты не копируются. Карты рисуются процедурно, три иллюстрации — собственные локальные SVG.

Текущая раздача `intro-001` — контрольная партия, не вся кампания и не окончательное обучение. Validation record содержит исходное состояние, версии, SHA-256 и победный путь. Путь из начала не обещает победу после любого решения игрока. Ограниченный поиск честно различает UNKNOWN и UNSOLVABLE.

В Android подключены реальные SDK-адаптеры; браузер не показывает фиктивную рекламу и не выдаёт рекламные награды. Скомпилированный APK не подтверждает реальный показ и доставку аналитики. [Устройство интеграции](docs/platform/NATIVE_SERVICES.md), [конфигурация и релизная приёмка](docs/platform/RELEASE_CHECKLIST.md). Следующий практический шаг — 20 собственных отредактированных раздач и расширение ядра по ТЗ.

Для сопоставимой диагностики есть независимые URL-флаги `fxCards=0`, `fxLayout=0`, `fxCoins=0`, `fxParticles=0`; правила и сохранения они не меняют. Это средство будущего замера, а не измерение скорости телефона.
