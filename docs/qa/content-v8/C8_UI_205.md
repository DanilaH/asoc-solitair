# Раскладка и управление C8 · №205

[Задача #205](https://github.com/DanilaH/asoc-solitair/issues/205) · исходная сборка [PR #204, 5039f1f](https://github.com/DanilaH/asoc-solitair/tree/5039f1fbafcfebc399e36141826cc9ca6a59fe5d) · `c8-release-v1` · PRODUCT_ADAPTED · KIT IMPACT REUSE.

## Контракт

- Поле использует фактический прямоугольник внутри HUD, панели действий, рекламного резерва и системных inset. У каждого Deal один масштаб для карты 138×166. Верхний и нижний ряды идут слева с шагом 152 логические единицы. Количество ячеек включает предложения бонусов. Колода и веер меняют край по настройке. Шаг сетки от стороны колоды не зависит.
- При малой высоте первыми сокращаются свободные интервалы и полосы внутри стопок. Размер определяется шириной общей сетки, веера и высотой обязательных зон плюс плотностью исходной раздачи. Масштаб и оси не зависят от числа карт, оставшихся в колоде. Необходимые подписи доступны через Aa, включая полное слово в режиме просмотра.
- Счётчик ходов расположен в строке уровня. Aa имеет область 48×48 CSS px в панели действий, Restore занимает место в существующей строке сообщений. Таймер Unlimited использует 14 CSS px для цифр.
- Порог касания составляет 10 CSS px от точки нажатия и учитывает выход за порог в любой момент контакта. Источник tap → tap выделяется контуром. Порог сравнивается с координатами PointerEvent до пересчёта в координаты Phaser. Прерванный жест возвращается на подтверждённую доску.
- Контент WebView фиксирует textZoom 100 при создании, конфигурации и возврате Activity. Корневая типографика DOM фиксирует text-size-adjust 100%. Display Size меняет область раскладки.
- Бонус дня показывает существующую рубашку и открывает приз после подтверждения записи SaveStore. Совпадения видны как 1/3 → 2/3 → 3/3. Состав, календарь, случайный выбор и сохранённые выдачи принадлежат прежней модели. Активные и будущие запасы помощников отображаются в отдельных списках.

## Доказательства и пределы

`ASOC_QA_C8_GEOMETRY=1 VITE_ASOC_PROFILE=c8-release-v1 npx vitest run tests/unit/c8-ui-geometry.test.ts --disableConsoleIntercept` проверяет 80 основных уровней, выборы обычной/облегчённой/усложнённой выдачи и повторов (242 уникальных выданных ID), все 28 Daily и 638 адресуемых сохранённых кампаний и QA-раздач. Всего 666 Deal ID и 96 320 проверок состояний и viewport. Исходные, заполненные и плотные стопки берутся из легальных префиксов путей, также проверяются доступный веер, исчерпание колоды и бонусные места. Архивный путь, который больше не применим, участвует с легальной частью префикса и исходной сохранённой геометрией. Этот прогон проверяет координаты и границы и дополняется реальными кадрами.

Браузерный прогон `tests/browser/c8-ui-205.spec.ts` фиксирует C8 manifest, фактический Deal ID, видимую область, координаты, CSS controls и скриншоты. Браузерный резерв под рекламу моделируется. Исходные скриншоты берутся из сборки PR204 на тех же снимках раздачи. Legacy C7 и C8 Preview имеют отдельные проверки. Артефакты GitHub CI привязаны к конкретному SHA.

Физический Android и live-показы проверяются по [протоколу Android](../mvp-20261124/ANDROID_ACCEPTANCE_PR204.md). На устройстве остаются 100/150/200% до и во время игры, отдельно Display Size, параметры native insets, читаемость плотных полос, TalkBack вне Canvas, громкость, тактильность, плавность, длинный no-fill/oversize, реальный возврат из рекламы и ILRD. Браузер измеряет CSS px. Android dp подтверждаются на устройстве. C8 остаётся кандидатом к приёмке.
