# Настройки движения, возвраты и урок о замке

Первый пакет по аудиту интерфейса от 23 ноября. Основа — [проверочная ветка #178](https://github.com/DanilaH/asoc-solitair/pull/178). Правила, версии раздач и учёт наград используют прежние контракты.

| Сценарий | Критерий приёмки |
| --- | --- |
| Первый показ урока о замке | Раздача на уровне 18 показывает «Один ключ» и один значок. Старая трёхключевая раздача показывает три. Отметка о первой встрече одно- и трёхключевого замков ведётся отдельно с сохранением исторической отметки для трёх ключей. |
| Возврат из дочернего окна | Из магазина возвращаемся в помощники, из оформления — в паузу или настройки, из помощников, открытых через настройки, — в настройки. Кнопка, крестик, Escape и системный Back используют тот же путь. Положение прокрутки и фокус на кнопке восстанавливаются. |
| Появление панели | Затемнение за 135 мс при входе с игрового поля или главной. Соседние окна сохраняют затемнение. Поверхность панели набирает непрозрачность за 75 мс, сдвиг заканчивается за 180 мс. Пауза и результат используют только прозрачность, чтобы зафиксированные кнопки и кошелёк сохраняли координаты. |
| Меньше движения | Системное предпочтение или настройка в игре включают режим для CSS, Phaser и кошелька. Смена системного предпочтения отменяет идущий полёт и сразу показывает подтверждённую сумму без записи в настройки. Ранее сохранённое предпочтение игрока сохраняет силу. |
| Доступность | 23 диалога получают имена из заголовков. Порядок фокуса в паузе совпадает с визуальным порядком. Задание дня и Календарь имеют две отдельные зоны от 44 px. Контраст кнопки календаря, мелких подписей и крестика усилен. |

Целевые сценарии находятся в браузерных проверках согласованности интерфейса, спецкарт, основной кампании C8 и проверочного магазина. Для APK выбран профиль specials. Магазин проверяется в отдельном профиле acceptance. Проверка системной кнопки Back, плавности и тактильного отклика на физическом телефоне остаётся открытой.

KIT IMPACT · REUSE. Использованы рекомендации motion и доступности и существующий runtime для блокировки ввода. Закреплённая версия mini-games-kit сохранена.
