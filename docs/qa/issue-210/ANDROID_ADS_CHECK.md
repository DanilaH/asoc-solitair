# C8 · №210 · проверка рекламы на Android

Сборка для QA использует `c8-release-v1` и `sdkMode=test`. Зафиксировать commit, package, version/code, отпечаток подписанта и SHA-256 APK. Повторять на чистом профиле и обновлении с принятой сборки. Production demo и коммерческая атрибуция проверяются в отдельных прогонах. Не публиковать ID рекламных блоков, ключи, рекламные идентификаторы или сырые SDK payloads.

## Уточнение №210 · source-shaped-pause-r2

Тестовый C8 использует общий момент подтверждённого fullscreen. Переход к уровню 3+ проверяет 120 секунд с запуска и последнего показа. Coffee доступен и в обычной кампании, и в доступной ежедневной игре. Кандидат использует 180 секунд, одно ожидающее окно и повторяемый показ без обязательного лимита на попытку. Сохраняются количество показов, идентичность раздачи и уровень/сложность. Настройки порога ходов и максимума оставлены конфигурируемыми. Успешный показ обновляет общий clock. В нажатии, предложении, анимации победы, фоне и во время сохранения пауза ждёт. Закрытие interstitial не выдаёт монеты. No-fill ограничивает повторные запросы без обновления durable clock.

Проверить по два реальных показа в одной длинной партийной и одной Daily попытке и убедиться, что после следующего интервала допускается третий. Тест с программным временем покрывает три записи обоих режимов, но не служит доказательством SDK показа.

## Проход аудита · source-shaped-pause-r3

- Тестовая сборка: C8 0.20.5, code 46. Ожидаемый профиль включает баннер с открытого уровня 2, с защитой обучения. Креатив и сохранение одного native view проверить на устройстве отдельно.
- Settings → Home даёт возможность `menu` по текущему уровню кампании. «Дальше» и повтор используют `level-start` с целевым уровнем в интерфейсе игры. Это решение для C8: очередность чтения уровня оригиналом на UI-границе остаётся открытой.
- `level-end` использует обратный флаг `levelStart`. В тестовом APK флаг включён, `theme` выключен. При проверке альтернативной конфигурации использовать тот же шлюз и общее окно 120 секунд.
- Coffee Break имеет общий с rewarded и остальными fullscreen показами журнал факта показа. Повтор по 180 секунд в той же кампании и текущей Daily покрыт ускоренным браузерным транспортом. Свидетельства настоящего demo fill, native px/dp, физической скорости и коммерческого ILRD остаются отдельными.
