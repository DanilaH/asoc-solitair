# C8 0.20.5 · проход по независимому аудиту №210

Базовый кадр и сборка для сравнения — PR211 `13ff796fd30b06ab2253816e859efda03b72034f`. Композиция «Карточный стол B», геометрия 138:166, модель поля, сохранения и цена каждого действия остались прежними. Новые визуальные счётчики получают значения подтверждённых изменений сохранения. Прерывание полёта завершает только презентацию.

Арт · четыре прозрачных спрайта для ежедневной раздачи, стопки карт, связанной темы и альбома. Происхождение, размер мастера, параметры экспорта и хеши в [audit-icon-export.json](audit-icon-export.json).

KIT IMPACT · REUSE. Применены арбитраж полноэкранной рекламы, раздельный учёт shown и earned, видимые границы касаний и правила прерывания движения. Runtime pin не менялся. Обновление [источника P21](../../porting/P21_AD_PLACEMENTS.md) привязано к точной статической ревизии исследования, без выводов об активном remote config и оригинальных показах.

Физический Android описан в [отдельном протоколе](ANDROID_ADS_CHECK.md). На браузерном стенде callbacks транспорта и отрисовка приложения воспроизводятся отдельно от реального SDK, dp, TalkBack и коммерческого ILRD.
