# P35 · Проверяемые версии банка

`src/content/signed-bank.ts` реализует автономный приём собственного банка через внедряемый транспорт. Проверяется подпись ECDSA P-256 заранее доверенным публичным ключом, SHA-256 точного payload, типы, объём, канонические новые ID и полный выигрышный маршрут. Действующие локальные позиции не перезаписываются. Новый банк выбирается только для новой попытки. Архив сохраняет все уже проверенные ревизии; исходный ID продолжает разрешаться после обновления и локального отката. Откат не снижает максимальную принятую ревизию для входящих обновлений.

Сбой сети, таймаут, обрыв, неверная доверенность, изменённый payload, неправильный путь или сбой записи оставляет последний применимый банк или базовые локальные раздачи. Неоднозначная запись подтверждается только обратным чтением точного снимка. Первый вызов обновления читает архив до записи. Путь по умолчанию не обращается к сети. Для реального развёртывания нужны адрес и собственный доверенный ключ выпуска; тестовый ключ используется только в тестах.

11 unit-проверок в C8, включая попытку с прежним ID после появления нового банка. [G1](../qa/content-v8/G1_LOCALE_LONG_CAMPAIGN_AND_REMOTE_SOURCE_2026-11-21.md) подтверждает исходное имя ApplyRemoteOverrides. **BLOCKED_EXTERNAL** для схемы оригинального ответа, реального включения, подписывания, порядка и удалённой политики. Офлайн-адаптер игры не заявляет совпадение с оригинальной сетью. KIT IMPACT: REUSE выбранной дисциплины неизменяемых ID и локальной проверки.
