# B2 · рекламные показы, выплаты и бесплатные поверхности

Задача #195 и ADS ТЗ из PR #194. Основание B1 — PR #197.

| Поток | Контракт кандидата |
| --- | --- |
| Показ P20 | Отдельный nonce до обращения к SDK. Сохранённая запись связывает nonce, исходную попытку, Deal и placement. Показ обновляет общий cadence по фактическому shown. Earned начисляет награду. Оба порядка проходят тест, включая загрузку сохранения между событиями. |
| Победа | Основная выплата сохраняет текущий баланс. Новая победа фиксирует собственную версию, базовую сумму и бонус за ходы. x3/x5 умножают только базу, третье подходящее предложение фиксирует x5. Повтор открытия одной победы сохраняет фактор. Архивные quotes исполняются по старой сумме. |
| Монеты | Бесплатная выдача 30 монет один раз в UTC-день на L16+, затем необязательное rewarded 30 с текущим 24-часовым интервалом. Это продуктовый кандидат на основе прежней суммы +30. Поздний earned относится к дню сохранённого запроса и сохраняет действующий интервал после выдачи. |
| Пауза | Одна внутрипартийная пауза AdsBreak. Опциональные монеты относятся к rewarded-поверхности. Старые начисления Coffee остаются читаемыми. |
| Провайдер | Один список placements для test и подтверждённого live. Новые live reward-offers открываются явным нативным допуском. Требуются действительные units, конфигурация и физическая Android-приёмка. |
| ILRD | Подтверждённое SDK-впечатление несёт формат, placement, валюту и сумму в микроединицах. Сохранённая отметка убирает дубли. В аналитике это оценка показа SDK. Доставку в live-аккаунт ещё предстоит подтвердить. |
| Сезон | Текущая бесплатная дорожка учитывает первые победы и выдаёт существующую награду без платёжного провайдера. |

Проверены x3 на базе 50 + 25, итог 175, x5 итог 275, оба порядка shown/earned, неизвестный nonce, повторный показ, полуночная граница, дневная выдача offline и отсутствие награды при no-fill. Проверка человеческого баланса остаётся открытой.

Осталось для B2/B4: полноценные каналы приобретения отдельного права Random Joker/Unlimited, общие ресурсы Definition/Shuffle, неплатные события готового контекстного диспетчера, live-доставка AppMetrica, фактический banner inset, пауза/возврат и проверка каждого SDK placement на телефоне. Платные семейства и их существующие права сохранены в дорожной карте. Расходы, реальные доходы, частоты и параметры live-оригиналов остаются неизвестными.
