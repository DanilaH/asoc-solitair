# Плавность игры 0.18.2

Экспериментальный пакет поверх 0.18.1 и Content 7. Все четыре изменения принадлежат представлению. Scene принимает данные уже сохранённой попытки. Правила, порядок карт, начисления и настройки SDK проверяются по исходной ветке.

| Сцена | Изменение | Проверка |
|---|---|---|
| Победа на 1-м → «Дальше» → 2-й | Раздача начинается в первом кадре новой сцены. Карты приходят по колонкам. Перенос из готовой колонки сохраняет движения соседних карт. | Настоящий тап по уже лежащей карте, пока часть соседних карт ещё раздаётся. Сравнить точный результат с моделью. |
| Стопка на 76-м | У трёх и более карт короткое сжатие при посадке. В нижней стопке задние карты слегка сближаются и возвращаются на места. | Законный перенос из маршрута C7, точное сравнение доски и Undo. |
| Переворот на 49-м | Закрытая карта начинает открываться, когда уходящие карты освобождают её область. Если траектории пересекаются до конца, открытие привязано к посадке. Открытие за замком по-прежнему следует за ключом. | Законный ход с переворотом и Undo, отдельные проверки ключей и контакта. |
| Обычная победа | Появление результата привязано к показу последней категории и завершению уже начатой выплаты за серию. При задержавшемся кадре декоративный показ без финального бонуса ограничен 720 мс. | Сценарий без финального бонуса и регрессии кошелька в обоих режимах движения. Баланс проверяется в момент открытия окна и после итоговой выплаты. |

На 4-м уровне Content 7 все карты открыты. Для проверки нового переворота используется 49-й. Браузер показывает отрисованные движения и проводит настоящие касания. Отзывчивость, вибрация и ощущение веса на Android остаются для плейтеста.

## Результаты проверок

- В Chromium прошли 62 целевых проверки на двух мобильных размерах. В сценарии без бонуса за серию запись победы опередила открытие окна на 298–322 мс. В сравнительном ролике для компактного профиля измерено 931 мс на 0.18.1 и 309 мс на 0.18.2.
- `npm run check` прошёл 193 проверки. `npm run qa:rules` сверил 203 расклада, 311 маршрутов и 363 742 перехода. Компиляция TypeScript и сборка production также прошли.
- Android CI собрал подписанный preview APK 0.18.2 с кодом 29. Сертификат совпадает с предыдущим preview, а все 208 веб-файлов совпадают со сборкой, проверенной в Chromium. В APK подтверждены тестовые идентификаторы объявлений и пустой ключ аналитики. [Данные сборки и подписи](source-apk.json).
- Плейтест Android остаётся открытым. Он нужен для оценки реального касания, частоты кадров, звука и вибрации.

**KIT IMPACT: NONE.** Тайминги и владение состояниями относятся к карточной сцене. Приложение продолжает использовать закреплённые компоненты кошелька, ввода и рендера.
