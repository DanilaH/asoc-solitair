# C8 · №210 · проверка рекламы на Android

Сборка для QA использует `c8-release-v1` и `sdkMode=test`. Зафиксировать commit, package, version/code, отпечаток подписанта и SHA-256 APK. Повторять на чистом профиле и обновлении с принятой сборки. Production demo и коммерческая атрибуция проверяются в отдельных прогонах. Не публиковать ID рекламных блоков, ключи, рекламные идентификаторы или сырые SDK payloads.

| Сценарий | Проверяемый результат |
| --- | --- |
| L1–2, затем открытие L3. Home, игровое поле, переключение campaign/Daily и parked attempts. | Единый резерв при открытии по прогрессу. До L3 пустой полосы нет. Настоящий creative внутри безопасного прямоугольника. |
| После paint перейти Home↔Game шесть раз. Снять обычную смену экрана и маршрут через Settings. | Обычные переходы сохраняют native view, ширину, запрос и поколение при одинаковой геометрии. В Settings креатив скрывается, на возврате тот же SDK view. |
| Insets / Display Size / узкий экран / background / потеря фокуса / обучение / недоступный слот. | В логах размеры CSS, px/dp, safe bounds, non-overlap и identity. Резерв сохраняет геометрию при временном скрытии. Не требуется повторно открывать экран для разрешённого retry. |
| Interstitial · переход «Дальше» после L5 при трёх новых победах и 120s. Затем отмена, no-fill и повтор. | Отдельно preload, show request, actual impression, dismiss, foreground. Не учитываются L1–5, daily или повторная победа. При no-fill игра доступна. |
| AdsBreak · L16+, допустимая сложность, больше десяти оставшихся ходов, прошли 180s. Во время границы удерживать карту, открыть Aa или паузу. | Креатив появляется в безопасном idle после завершения взаимодействия; пауза одна. Сразу после rewarded и во время кульминации показ запрещён. |
| Rewarded · отказ до показа, отказ до earned, earned с background/reload и повторной доставкой. | Бесплатная часть и заработанные права доступны. Дубликат receipt не даёт ресурс повторно. ILRD отдельно от show и earned. |
| TalkBack, fontScale 100/150/200 и повторное создание Activity. | WebView держит textZoom=100, основные действия доступны, текст и баннер остаются в safe bounds. |

Для демонстрационного APK можно сверять фазы и `banner placed generation/view/rect` через `adb logcat -s SolitaireAds`. Тесты транспорта и JUnit покрывают программные контракты. Paint, реальный SDK/ILRD и физическое ощущение требуют видео и логов устройства.

В исходном BoardScene три подготовленных спрайта перелёта ключей существовали даже в простое. Проверка длины пула делала idle недостижимым. Учитывается видимый полёт и активная презентация ключа. Browser-тест проверяет отложенный запрос после модалки и no-fill на границе транспорта Android.

KIT IMPACT · REUSE. Применены правила числового JSON-счётчика, дробного измерения, стабильного владения native view и раздельных событий request/show/earned. Pin runtime сохраняется.
