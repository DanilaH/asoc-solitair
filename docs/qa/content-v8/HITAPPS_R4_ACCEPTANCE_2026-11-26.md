# Солитёр · генератор Hitapps и Rules4

Кандидат 0.20.9, Android code 50. База изменений — #213 поверх #212. Режим приёмки включается `VITE_HITAPPS_SOURCE_QA=1`. Android CI включает его в подписанном тестовом APK. Сертифицированные раздачи восстанавливаются по ID и при выключенной новой выдаче. Решения #210 действуют в обычном выпуске и сохраняются в кандидате.

## Как повторить

1. `npm run check` и штатные browser/Android jobs проверяют совместимый режим. `VITE_HITAPPS_SOURCE_QA=1` включает браузерную проверку выдачи, возобновления Rules4, смены геометрии, повторной игры в ту же раздачу и списания жизни. Сценарий L66 сохраняет три ключа и замок после смены расклада.
2. `npm run qa:hitapps-r4` проверяет штатный селектор выдачи, паспорт, восстановление и обычный повтор для каждого из 65 уровней при штрафах −5, 0 и +10. Каждая упакованная раздача и вариант бюджета отдельно прогоняются игровыми правилами и независимым симулятором. В отчёте остаются seed, резерв ходов и число позиций с несколькими переносами. `HITAPPS_AUDIT_BOTS=1` добавляет исходные стратегии.
3. `HITAPPS_EVIDENCE_DIR=/path/to/research/games/association-solitaire npm run qa:hitapps-source-r4` проверяет Git-хеши исходных матриц и вызывает потребительские функции. Исходная ревизия исследования — `81da64b3f11acc1a4e4e9ff69c06e3baea5f8481`. Пройдены 5 972 строки специальных правил и 2 248 строк условий размещения, overrides и паттернов. Три префикса RNG являются модельными примерами.
4. Генерация идёт в `tools/content/build-hitapps-r4.ts` и `build-hitapps-r4-coverage.ts`, отбор в `hitapps-source-pipeline.ts`, упаковка в `pack-hitapps-r4.ts`. Для воспроизведения покрытия собрать `build-hitapps-r4-coverage.ts` с `VITE_ASOC_PROFILE=c8-release-v1` и передать уровень, начальное смещение seed и число попыток (`280 160` с `HITAPPS_COVERAGE_VISITS=110` для уровней с механиками, `280 700` с `HITAPPS_COVERAGE_VISITS=0` для остальных). Упаковка проверяет оба движка и строит допуски бюджета. Метки `fixed-control` и `feature-check` сохраняют контрольные экземпляры, `campaign` допускает раздачу к штатной выдаче.

## Числа и границы

Пороги 70/90 и штрафы −5/+10 переиспользуют утверждённую политику продукта. Коэффициенты Easy Deals 8/12/16 принадлежат версии `hitapps-balance-v1`. Проверка использует распределения запаса ходов и доли использованного бюджета, а также альтернативы на победном пути. Человеческая сложность и доля побед требуют отдельного плейтеста.

Два симулятора подтвердили победные маршруты 194 сертифицированных раздач кампании, включая локализованные варианты, и перепроверили 21 721 переход. Банк содержит 228 базовых определений, в том числе 80 новых раскладов для 40 уровней. Проверены 195 пар выдачи и повтора на всех 65 уровнях с 16-го по 80-й. Сохранены три ключа для L18/L66, один ключ для L26, заморозка, связки, пазлы, золото и стартовые карты. Сохранены бесплатные повторы и цены восстановления L16/L22/L30, право платной перетасовки L30/L33/L36/L39 и прежняя группа однократной награды за золото.

Priority дал сертифицированные кандидаты для всех девяти проверенных уровней. Equality проверил по 100 кандидатов для тех же уровней и во всех случаях вернул обычную выдачу после проверки допуска. Положительные условия и обмены Equality покрыты исходными матрицами.

Серверные параметры, весь исходный игровой цикл, порядок всех перекрёстных событий и списание хода остаются `SOURCE_UNKNOWN`. В Rules4 принята локальная цена в один ход за принятый игровой ввод, а автоматические эффекты происходят внутри того же хода. Локальные решения также определяют разрешённый поиск Магнита, эффект Молотка на обычную открытую карту, исходную раскладку отдельно заданных половинок, предотвращение конфликтов координат, выбор дополнительного скрытого золота и приз Gold Rush. Локальные условия и сравнение нативных функций перечислены в [ТЗ G0–G6](../../porting/HITAPPS_GENERATOR_AND_SPECIALS_TZ_2026-11-26.md).

Ветку выпуска и нативный пакет оценивать по точному коммиту в CI. Поведение на настоящем Android, рекламные SDK и коммерческая конфигурация остаются отдельными этапами приёмки.
