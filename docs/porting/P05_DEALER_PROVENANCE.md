# P05 · Две независимые модели раздачи

| Модель | Реализация и доказательства |
| --- | --- |
| Hitapps ordinary / Priority | `EmbeddedRandom`, 10 проходов по позициям, отдельный источник значения для отрицательного запроса. Priority восстанавливает выбранное начальное значение на границе 100 попыток. Воспроизведены четыре числовых хэша, все 15 начальных раздач C8 и случаи отрицательного запроса. [Исследование Hitapps](https://github.com/DanilaH/mini-games-kit/blob/4b916c834e99b9208d194e2838dc2c082898ed2d/research/games/association-solitaire/2026-11-18-hitapps-plain-replay/README.md) |
| AZUR ordinary | Перечисление тем с лидером перед участниками. Положительный загруженный count приходит из явного входа, при большем числе карт используются циклические ссылки и отдельные порядковые номера. Одна убывающая перестановка временного списка через внедрённый Range. В трассе есть исходный порядок, shuffled, открытые карты, столбцы и вход колоды. Unit проверяет 3/4/5 столбцов, точные вызовы Range, пустую тему и сохранение исходного списка. [GenerateCards](https://github.com/DanilaH/mini-games-kit/blob/6ebc2c19798730e272ca6f8675dbccf6b7180e15/research/games/association-solitaire/2026-11-20-azur-art-sprite-card-count/README.md) · [Копия списка](https://github.com/DanilaH/mini-games-kit/blob/5e4588c4a58befd46358a62c10d364de68a76e40/research/games/association-solitaire/2026-11-20-azur-deal-copy-correction/README.md) |
| AZUR tutorial preset | Отдельная ветка первого уровня. Отрицательный индекс лидера, авторский порядок столбцов и колоды. При недоступном пресете вызов обычного дилера. [Проверка пресета](../qa/content-v8/AZUR_PRESET_AUTHORING.md) |

`npm run qa:azur-ordinary` пишет собственный офлайн Deal `authoring-azur-ordinary-001-r1` и JSON-трассу в `.authoring/azur-ordinary/`. Девять карт, восемь заданных значений Range, 12 ходов до победы. SHA-256 раздачи `b5e213a9062e30ecea97c1853286c9d9cad4255f35833076fc7d24892f39f84d`. Движок Rules 3 и независимый oracle согласились после каждого хода, включая два полных повтора колоды. Прежний preset на 14 карт и 19 ходов сохраняет SHA-256 `3a35a71bb711356a7c91818486b17f156ae513af40e5380d4aed263f19da89ab`.

Проверено семь назначенных ID, включая разные условия отсутствия переносов и исчерпания бюджета. Обычная кампания и сохранения продолжают использовать прежние Deal IDs. Все 114 механизмов сохраняются в реестре.

P36 требует оригинальные эпизоды. Открыты активное состояние Unity RNG, фактически загруженные наборы карточек, live-настройки Priority, оригинальные afterShuffle/afterFinal. P34 отдельно проверяет асинхронную загрузку изображений и локализованный бюджет.
